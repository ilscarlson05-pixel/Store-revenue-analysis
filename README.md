# Revenue by Store Size and Country (SQL Project)
## 📊 Overview
This project analyzes **total revenue generated by stores of different sizes across countries** during 2023.  
It helps understand which store size (small, medium, or large) contributes most to overall sales in each region.

Using **SQL aggregation and conditional logic**, the analysis calculates revenue by store size using the `SUM` and `CASE WHEN` statements, while excluding online stores for accurate country-level insights.

---

## 📚 Dataset Used
- **Tables Involved:**
  - `sales` — Contains transaction data such as `quantity`, `netprice`, `exchangerate`, and `orderdate`
  - `store` — Contains store details like `storekey`, `countryname`, and `squaremeters`
- **Columns Used:**
  - From `sales`: `storekey`, `quantity`, `netprice`, `exchangerate`, `orderdate`
  - From `store`: `storekey`, `countryname`, `squaremeters`
- **Data Period:** 2023  
- **Data Source:** Company database (simulated data for SQL analysis)
## 🧩 Problem Statement
Calculate the total revenue generated by stores of different sizes in each country in 2023.  
This helps analyze revenue contribution from various store sizes across regions.

**Store Size Definition:**
- Small: < 1000 m²  
- Medium: 1000–2000 m²  
- Large: > 2000 m²  

**Requirements:**
- Use `SUM` with `CASE WHEN`
- Exclude `"Online"` stores
- Group by country name
- Order by country name

## 💡 SQL Solution
```sql
SELECT
    st.countryname,
    SUM(CASE WHEN st.squaremeters < 1000 THEN s.quantity * s.netprice * s.exchangerate ELSE 0 END) AS revenue_small_store,
    SUM(CASE WHEN st.squaremeters BETWEEN 1000 AND 2000 THEN s.quantity * s.netprice * s.exchangerate ELSE 0 END) AS revenue_medium_store,
    SUM(CASE WHEN st.squaremeters > 2000 THEN s.quantity * s.netprice * s.exchangerate ELSE 0 END) AS revenue_large_store
FROM
    sales s
    LEFT JOIN store st ON s.storekey = st.storekey
WHERE
    s.orderdate BETWEEN '2023-01-01' AND '2023-12-31'
    AND st.countryname != 'Online'
GROUP BY
    st.countryname
ORDER BY
    st.countryname;
